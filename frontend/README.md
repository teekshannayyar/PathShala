# PathShala frontend

React 19 + Vite app for PathShala. Setup, scripts, environment variables and deployment are documented in the [root README](../README.md); routes and architecture are in [HANDOFF.md](../HANDOFF.md).

```bash
npm install
cp .env.example .env.local   # VITE_API_URL, VITE_GOOGLE_CLIENT_ID
npm run dev                  # http://localhost:5173
npm run lint
npm run build
```
